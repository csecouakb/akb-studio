# AKB Studio

Offline-first lightweight video editor focused on singing videos, voice enhancement, basic visual adjustments, background tools and local export.

## V1 goals

- Installable PWA for Android and desktop
- Local media import and preview
- Trim controls and playback
- Visual adjustments and filter presets
- Voice Studio presets: Raw Clean, Studio, Unplugged, Warm, Clear Vocal, Echo, Reverb
- Background blur/color/image controls
- No subscription and no required cloud upload for core editing

## Development

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite.
